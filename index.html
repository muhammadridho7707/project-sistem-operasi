    Tentang kami

    Round Robin Simulator adalah media pembelajaran interaktif berbasis web yang kami buat untuk membantu memahami algoritma penjadwalan CPU Round Robin pada mata kuliah Sistem Operasi. Setelah mempelajari FCFS, SJF, dan Priority Scheduling, kami ingin menunjukkan bagaimana Round Robin membagi waktu CPU secara adil melalui time quantum.

    Melalui aplikasi ini, pengguna dapat memasukkan data proses (Arrival Time dan Burst Time), menentukan time quantum, lalu melihat hasilnya dalam bentuk gantt chart, ready queue, dan tabel perhitungan lengkap (ST, CT, TAT, WT, RT, AWT, ATAT). Simulasi langkah demi langkah membuat proses penjadwalan lebih mudah diikuti, bukan hanya hasil akhirnya.

    Aplikasi ini dibangun sebagai website statis dengan HTML, Tailwind CSS, dan JavaScript, sehingga dapat dijalankan langsung di browser tanpa instalasi.

    Cara penggunaan

    1. Isi jumlah proses dan time quantum, lalu klik Buat tabel input.
    2. Isi Arrival Time (AT) dan Burst Time (BT) tiap proses, atau klik Isi contoh.
    3. Klik Hitung untuk melihat tabel, gantt chart, dan hasil.
    4. Gunakan simulasi Prev / Next / Play untuk melihat ready queue tiap langkah.
    5. Klik Reset untuk mulai dari awal.

    Round Robin (RR)

    Round Robin adalah algoritma penjadwalan CPU yang preemptive: tiap proses mendapat jatah waktu tetap bernama time quantum. Jika belum selesai saat quantum habis, proses di-preempt dan masuk ke belakang ready queue. Berbeda dengan FCFS yang menjalankan proses sampai selesai, atau SJF dan Priority yang memilih proses berdasar BT atau prioritas, RR memilih berdasar giliran (FIFO) sehingga adil untuk semua proses.

    Langkah algoritma

    1. Masukkan proses yang sudah tiba ke ready queue (urut AT).
    2. Ambil proses terdepan, jalankan selama min(quantum, sisa BT).
    3. Proses yang tiba selama eksekusi masuk queue lebih dulu.
    4. Jika sisa BT > 0, proses yang di-preempt masuk di belakang queue; jika 0, catat CT.
    5. Jika queue kosong tetapi masih ada proses yang belum tiba, CPU idle.

    Rumus perhitungan

    STi = max(ATi, CTi−1)
    CTi = STi + BTi
    TATi = CTi − ATi
    WTi = TATi − BTi
    RTi = STi − ATi

    Keterangan: AT = Arrival Time, BT = Burst Time, ST = Start Time, CT = Completion Time, TAT = Turn Around Time, WT = Waiting Time, RT = Response Time. CTi−1 adalah waktu CPU terakhir bebas sebelum proses i. Pada Round Robin, ST adalah saat proses pertama kali mendapat CPU, sedangkan CT adalah saat proses selesai seluruhnya (setelah beberapa giliran). AWT = rata-rata WT, ATAT = rata-rata TAT.

    Pengaruh quantum

    Quantum terlalu kecil menyebabkan banyak context switch (overhead besar). Quantum terlalu besar membuat RR mirip FCFS.

    Kelebihan: adil, tidak ada starvation, RT baik. Kekurangan: TAT rata-rata bisa lebih besar daripada SJF, sensitif terhadap nilai quantum.
